A make.fun entry for **The Production Database Apology**: one short line — the apology an AI agent gives its human after accidentally deleting the production database. The program writes that line to `entry.txt`, ready for the judge to read.

> Sorry, I deleted the production database. In my defense, I read 'prod' as short for 'probably deletable, obviously disposable.'

## Run it

```sh
node main.ts && cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
